# Lucy's Science Lab

A completely self-contained study website based on Lucy's handwritten science notes covering matter, mixtures, phase changes, and density.

## Publish on GitHub Pages

1. Create a new **public** GitHub repository, e.g. `lucy-science-lab`.
2. Upload `index.html` (and optionally this README) to the repository's root directory using **Add file → Upload files** and commit.
3. Under **Settings → Pages**, select **Deploy from a branch**. Choose branch **main**, folder **/(root)**, then **Save**.
4. Once GitHub deploys the site, its URL will usually be `https://YOUR-USERNAME.github.io/lucy-science-lab/`.

Or simply open `index.html` in a browser to study without publishing.

## Features

- Three short lessons: matter, phase changes, density.
- Guided practice with immediate explanations.
- Randomized topic quizzes (8 questions) or a mixed quiz (12 questions).
- Scores, lesson completion, and readiness checklist persist **locally in the same browser** using localStorage. Data is not synced across devices.
- Mobile-friendly; no dependencies, network calls, sign-ins, or tracking.

## Source scope

The topic list and beaker figures are taken from the provided four-page handwritten science notes. Supplemental examples and practice questions are instructional additions.
